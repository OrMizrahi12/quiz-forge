# Content policy

- Quiz Forge writes practice questions about the course's own lesson notes, and nothing else.
- An item never carries personal data (8.2 minimizes before sending and redacts before storing).
- Everyone who uses Quiz Forge is bound by Anthropic's Usage Policy.
- A refusal is an answer, not an error: it is logged, the same request is not sent again, and the lesson goes to a
  person (7.1).
- Practice questions are educational content, not one of the Usage Policy's high-risk recommendations. If Quiz Forge
  ever graded an exam that decides a certification, outside multiple-choice testing, the high-risk requirements would
  apply: a qualified person reviews before anything is delivered, and the learner is told AI was involved.
