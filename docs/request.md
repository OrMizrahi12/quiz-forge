# The request (a scenario written for this course: Northwind Learning is invented)

> We run online courses and want practice exams for them. Each course has its own lesson notes and its own exam
> blueprint with domain weights, so the tool must work for any of our courses. We need about 2,000 approved
> questions a quarter. Every question must point to the lesson text it comes from, and a reviewer on our team
> approves it before any learner sees it. Approved questions go into our learning platform's import format.
> Learner data must never be sent to an AI model. Our customer contracts say processing happens in the US only.
> We have a fixed budget per quarter. When a reviewer asks to regenerate a question, they shouldn't wait more
> than a minute. It has to be fast, secure and handle a lot of content.
