# Lesson 0.3: Claude Desktop tour

Claude Certified Associate – Foundations (CCAO-F) · Section 0: Start Here · Lesson 3 · 10:55

## Description

A guided first tour of Claude Desktop for someone who has never used it. You meet the three places to work (Chat, Cowork and Code), the toolbox behind the plus button, the model picker, and the Settings pages that decide what Claude may do. Each of the seven main tools (Projects, Artifacts, Research, Memory, Skills, Connectors and code execution) gets one plain line and its place in the app. You also see where those facts come from: Anthropic's blog, the Help Center and the official exam guide. Then you run a real first chat. Sonnet 5.5 turns this course's real Module 1 lesson list into a five-day study plan, Haiku 4.5 shrinks it to a sticky note, and both answers get checked against the list. The lesson ends with one exam-style scenario, reasoned out loud.

## Learning outcomes

By the end of this lesson you can:

1. Find your way around Claude Desktop: Chat, Cowork, Code and Settings.
2. Say in one line what each main tool does and where it lives.
3. Run your first chat, and switch models when the job changes.

## Your app may look different: the Chat | Cowork switch

On September 16, 2026, Anthropic announced that Claude Cowork and chat are merging into one Claude. The new experience is rolling out in stages, starting with Pro and Max plans on web, desktop and mobile, with more plans to follow. Accounts on the same plan get it at different times, and there is nothing to turn on. This lesson was recorded on 2026-10-03 on an account that did not have it yet, so the message box still shows the **Chat | Cowork** switch.

**How to tell which one you have.** The Help Center's own test: "If you're on a Pro or Max plan and your message box still shows "Chat" and "Cowork" options, you don't have it yet." If your switch is gone, you have the merged layout. There's no mode to pick: you just ask in any conversation, and Claude can take on the bigger, multi-step work Cowork used to do. Once an account has moved over, it can't switch back.

**What stays and what moves** (Help Center, "What happened to Claude Cowork?" and "What's in a new place"):
- Stays: "The model picker and the "Code" tab are where they were." Your chats, Cowork tasks, projects, connectors, skills, artifacts and files carry over. The `+` menu, Settings and Customize work as shown in the lesson.
- Moves: Cowork tasks now sit with your chats in **Recents**. There's no web search toggle, because Claude searches the web when it helps. **Research** is under `+` → Research, or you type `/deep-research`. Cowork's Global instructions become part of **Instructions for Claude** in Settings > General.

Sources: Anthropic blog, *Claude Cowork and chat are now one Claude* (September 16, 2026), https://claude.com/blog/cowork-is-now-claude, and Claude Help Center, *Claude Cowork and chat are one Claude*, https://support.claude.com/en/articles/16761823-claude-cowork-and-chat-are-one-claude (both checked 2026-10-03).

## Key terms

- **Surface:** a place in Claude Desktop where you work: Chat, Cowork or Code.
- **Cowork:** handing Claude a bigger, multi-step job to finish while you do other things. Since September 16, 2026 it is merging into every conversation, account by account.
- **Model picker:** the menu next to the send button that chooses the model (Haiku, Sonnet or Opus) and its effort. A switch applies from the next reply.
- **Connector:** a link that lets Claude read from and act in your other apps, using your own permissions in each one.
- **Capability:** a switch in Settings → Capabilities for what Claude may do, like code execution and file creation.

## The seven tools in one line each

| Tool | What it does | Where it lives (both layouts) | Taught in |
|---|---|---|---|
| Projects | Workspaces with their own chats, files and instructions | Sidebar → Projects; `+` → Add to project | 5.1 |
| Artifacts | Things Claude makes that you'd put in front of someone (a document, a deck, a small tool), opening beside the chat | Beside the chat; sidebar → Artifacts; Settings → Capabilities | 3.6 |
| Research | Many searches that build on each other, then one report with citations you can check, in minutes | `+` → Research (merged layout: also `/deep-research`) | 4.2 |
| Memory | Carries context from your past chats into new ones. You can turn it off for one chat in the `+` menu before the first message | `+` → Memory; Settings → Memory | 1.4 |
| Skills | Saved how-tos that Claude loads when a task needs one. They need code execution | `+` → Skills; Settings → Customize → Skills | 5.3 |
| Connectors | Links to your other apps, like Gmail or Drive, with your own permissions | `+` → Connectors; Settings → Customize → Connectors | 5.2 |
| Code execution and file creation | Claude runs code on a server to create and edit documents, spreadsheets, presentations and PDFs. Skills and artifacts depend on it | Settings → Capabilities | 3.6, 4.3 |

## The exam link

- Task statement 3.1 (Domain 3, Product and Model Selection): "Select appropriate Claude product features (Projects, research mode, chat, artifacts)." This is the Platform Awareness skill from Lesson 0.2: knowing what each tool can and can't do.
- §7, How to Prepare: "Review official Anthropic documentation and help articles for Claude features such as Projects, Artifacts, Memory, Skills, and Code Execution."
- Code is in scope only as escalation awareness: knowing when to hand technical work to a developer.

**The lesson's practice scenario (original, not from the exam).** A marketing coordinator must compare five competitors' pricing and features by Friday, and her director wants sources he can check. The most appropriate way to use Claude is **B, turn on Research**. A quick chat on the fastest model (A) gives one answer without the sources. The Code tab (C) is for software. A Project built on last year's notes (D) starts from stale information. The Help Center says Research is for comprehensive gathering ("five or more tool calls") and "can do things like compare business competitors", with proper citations. She'd still check those sources.
